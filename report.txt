توضیحات:
۱. git add تغییرات انتخاب‌شده را برای ثبت آماده می‌کند؛ git commit تغییرات آماده‌شده را در تاریخچهٔ مخزن ثبت می‌کند.
۲. فایل .env نباید commit شود، چون ممکن است اطلاعات محرمانه مثل کلیدها و رمزها را در خود داشته باشد.
۳. git diff تغییرات ثبت‌نشده در staging area را نشان می‌دهد؛ git diff --staged تغییراتی را نشان می‌دهد که با git add آمادهٔ commit شده‌اند.
